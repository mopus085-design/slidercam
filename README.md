# SliderCam

Компактный **Android-пульт для моторизованного слайдера камеры** по Bluetooth LE. Статус: проектная спецификация (MVP).

## Цель

APK до **150 КиБ** (контрольный порог 250 КиБ): Java + системный WebView + локальные HTML/CSS/JS + BluetoothGatt. Ноль сторонних зависимостей, полная работа без интернета.

## Интерфейс (три раздела)

- **Пульт** — позиция каретки в мм, рельса с точками A/B, Video/Timelapse, сдвиг на 1/10/50 мм, большая кнопка «Стоп», снятие питания мотора (ESTOP + HOME)
- **Сцены** — сохранение и запуск съёмочных проходов
- **Устройство** — состояние, батарея в вольтах, обмен

## Принципы

- Движение — только по явному нажатию; редактирование полей ничего не запускает
- Блокировка редактирования во время хоминга и движения
- Перенос проверенных решений из Radio Messenger (очередь GATT, разрешения, разрыв связи)
